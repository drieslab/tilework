# Create a Fluid Tile Plan

Create an empty `freeTilePlan`. Populate bounds via `$bounds<-` or use
[`quadtreePlan()`](https://drieslab.github.io/tilework/reference/quadtreePlan.md)
to generate adaptive bounds automatically.

## Usage

``` r
freeTilePlan(...)
```

## Arguments

- ...:

  additional params passed to
  [`new()`](https://rdrr.io/r/methods/new.html).
